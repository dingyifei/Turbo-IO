## 更新了什么

- 以新版 **1.0.5.5 原厂 AP** 为底座重新移植，不把旧 1.0.4.12 AP 塞进新包；保留未被扩展覆盖的新原厂代码和配套负载。
- 延续四项同屏菜单、时间/电量、仪表盘与编辑协议、四槽小应用、导航、音乐、原生阅读、番茄、诊断、Watch 输入和全天智记共存等原生模块；各项仍有独立验收边界。
- **公开情境英语 TEL1**：手机读取本机已有的智记缓存，选定目标与片段，授权后用用户自己的模型生成题库，检查后发送；眼镜原生显示、每日有界学习、复习记录与按键/头控交互。
- 手机宿主加入 1.0.6（218）的精确版本/UUID 检查，匹配新版官方查询、下载、手机解压及正常 Mode 2 传输流程；默认锁定，不自动授权或刷写。
- **Dots 保留开发中入口与研究代码，尚未完成端到端交付**。不附私人 Bridge、ChatGPT 会话、订阅、隧道或服务凭据，不宣传为可直接使用的 Dots 对话产品。
- 未引入此前回退的 TBL1 手动亮度锁定/平滑实验；不要据入口推断某固件能力已存在。

“保留官方优化”指继续使用新底座与未改原厂负载，不表示已经逐项证明官方发布说明中的每项效果。官方说明包括显示、唤醒、蓝牙稳定性与定时调度改进；本轮不把这些说明当作自己的对照实测。

## 底层大概：为什么适配不容易

这不是改版本字符串或换一张 UI。旧版本的 **36 个补丁前置字节在新版同偏移 0/36 匹配**，函数、全局对象、启动段和 C++ 成员偏移都可能变化，不能整包平移地址。

1. **重新绑定函数和全局状态**：逐项检查 134 个原生绑定、入口/续跳、消息和文件通道、分配/释放及 LVGL 调用；短字节前缀只作定位线索，不当作 ABI 证明。
2. **重新核对对象内存布局**：原厂菜单对象 220→252 字节，扩展后 284 字节；系统头控状态 64→104 字节，扩展后 136 字节。轮询、回调发布/注销、寄存器保存、时区成员等也单独迁移，不能按旧结构写字段。
3. **重新验证生命周期与共存**：菜单选择、单实例前台、延迟释放、实体/Watch 输入、佩戴/点头摇头、息屏、原厂录音与智记冲突，分别通过真实新版指令与受控服务模型检查。
4. **手机 OTA 也重新适配**：新增 `bt_controller.bin` 后是 **15 个负载 + 1 份清单**；下载 SHA-256、解压文件、设备身份、版本、Mode 2、清单、每个待传分片均固定验证，不修改固件写入地址、不绕过校验。

离线验证包含 8 组原生 ARM 核心场景、512 组共存差分、13 组全局输入、12 组未改新版 BTH 头控调用及 26 组 ASan/UBSan 核心回归。这些使用模拟 OS/LVGL/蓝牙/传感器，**不代替硬件长稳、功耗或全量回归**。本次用户实刷反馈是另一层证据。

## 只改 application 的准确含义

相对 **新版 1.0.5.5 原厂包**，自定义修改只在 `nuttx_ap.bin`；其余 **14 个负载逐字节不变**。清单只更新 AP Size/MD5，整包 MD5/SHA-256 重新计算。34 处明确白名单写入（32 处分支及 2 处尺寸/计数），其他原厂 AP 字节、7 个启动复制描述、头部和尾部保留。

目标 UI/协议/业务就在 AP 中，因此不改 BTH、APC1、算法库、资源和安装组件，缩小变量和审计范围。**这是“自定义只改 AP 内容”，不是“OTA 只写 AP”**。本包是完整新版 OTA，会按原厂流程安装其他新原厂负载；它们相对旧 1.0.4.12 本来就可能不同。

## 开发者刷写步骤：完整一次操作

先完成匹配手机插件构建与自己的签名（已归档 / archived in git tag `archive/editions-2026-10`: `official-addon/tmig1-edition/README.md`）。**不提供合并 IPA 或代签，不能拿旧安装器强刷。**

1. 下载 Release 固件与 SHA256SUMS，执行 `shasum -a 256 -c SHA256SUMS`；不符立即停止。
2. 手机解锁，眼镜首页、无录音/智记/音乐/阅读/导航/对话，电量至少 50%，连接和供电稳定；关闭官方自动更新。
3. TurboIO → 设置 → 诊断与实验固件 → TMIG1，候选校验通过后开启「15 分钟只下载验收」。
4. 回官方固件页「检查更新」并下载，到「软件就绪」，先选「稍后再说」。在插件页核对官方解压目录，全部 16 个成员须一致。
5. 再从官方页检查版本，**两分钟内**到插件页「允许一次 TMIG1 整合迁移试刷」，输入 `TMIG1`；确认授权 1。该两分钟是授权前版本回读的新鲜度，不是传输时限；授权开始前上限 15 分钟。
6. **立即**回官方页「安装更新」→「开始安装」，只点一次，不需要等待作者核对。不要在升级期间强退 App、重启、断电、换连接或重复提交。
7. 等眼镜完成更新并**自然重启回首页**，确认没有剩余传输/安装后，彻底退出重开手机雷鸟 App，结束本次进程内升级保护，再测试同步和日常功能。状态不明或升级未结束时禁止重开。

超时也要区分是否已发送：只有明确“已开始 0 / 分片 0”、镜片无升级且无任务时，才可撤销未开始授权并重开手机 App，正常重新检查/授权。已经开始或状态未知，先保留脱敏错误和日志，**不盲目重试、不解除保护、不强制重启眼镜**。本包不开放未经核实的恢复/续传操作。

## 离线审计与完整 AP 重建

需要 Python 3（不要用 `-O` 禁用断言）和支持 Cortex-M33 的 LLVM：`clang`、`ld.lld`、`llvm-nm`、`llvm-objcopy`。本机仅复用 DevEco SDK 的 LLVM 工具链，**不引入鸿蒙代码、运行时或应用依赖**。

从仓库根目录，仅审计下载包：

```sh
python3 firmware-research/strix-1.0.5.5/build.py \
  --stock firmware-research/strix-1.0.5.5/stock/Strix-OS-1.0.5.5-original.zip \
  --audit /absolute/downloaded/TMIG1.zip
```

完整重建（输出目录必须不存在）：

```sh
python3 firmware-research/strix-1.0.5.5/build.py \
  --stock firmware-research/strix-1.0.5.5/stock/Strix-OS-1.0.5.5-original.zip \
  --llvm-bin /absolute/llvm/bin --out /absolute/new-tmig1-output
python3 firmware-research/strix-1.0.5.5/test_host_cores.py
```

公开 69 个 C 编译单元、汇编、生成头文件/图标、链接脚本和固定写入白名单；只包含一帧的动画引用沿用既有素材，未恢复多帧常驻动画。源码或工具链生成的模块哈希不一致时，构建停止，不会放宽校验出一份“近似”可刷包。所有脚本只做本机文件操作，不安装、不刷写。
