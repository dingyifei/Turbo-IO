# 固件研究

这里是原厂固件与研究资料，**不参与当前构建**。当前的 TurboIO 眼镜固件只有一个源码树：[`firmware/`](../firmware/README.md)，每个版本是一个 git 标签（`fw/tmg2` … `fw/tmg8`），`git show fw/tmgN` 可查看该版本的 ZIP SHA-256 与配对手机构建。

所有自定义包均为**非官方、高风险实验用品**。小白不要刷，日常使用请使用官方 App 与原厂固件。掉电、中断、错包或缺陷可能导致设备损坏；不保证回滚、恢复或救砖。

| 目录 | 内容 | 官方原版 |
| --- | --- | --- |
| [strix-1.0.5.5](strix-1.0.5.5/README.md) | TMIG1：迁移到 Strix OS 1.0.5.5 新底座、App 1.0.6（218）适配，2026-10-14 用户实刷兼容 | [官方原始 ZIP / SHA-256](strix-1.0.5.5/stock/README.md)，字节不变、未重封装 |
| [strix-1.0.5.5-tvp2](strix-1.0.5.5-tvp2/README.md) | TVP2：540×220 原生清晰投屏实验版（2026-10-23） | 沿用 1.0.5.5 原始 ZIP |
| [strix-1.0.4.12](strix-1.0.4.12/README.md) | 历史研究索引：图片、传图、导航、动图、音乐、阅读等，各有独立源码、手机门禁和验收边界 | [原厂负载归档](strix-1.0.4.12/stock/README.md)，负载未改、ZIP 重封装 |

版本号只是条件之一，还要核对 ZIP 哈希、官方宿主构建号、扩展标记及固定门禁。旧 iOS / Android 候选不能换文件名或哈希强刷新版；新 AP 不能简单平移旧补丁地址。

完整 OTA 不等于只写 AP。TMIG1 的自定义变化只在**相对新原厂包**的 application 中，其他负载随官方底座升级，并非固定在旧版本。原厂归档用于分析与受控恢复研究，不是通用一键救砖包。
