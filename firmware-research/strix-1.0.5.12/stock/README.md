## Use

TMG10 is built on this base (`stockBase`, `stockZIP`, `stockAP` and `stockMembers` in `firmware/build-inputs.json`). The address map from 1.0.5.5 to 1.0.5.12 is `firmware/baseline/rebase-1.0.5.5-to-1.0.5.12.json`, generated by `firmware/tools/rebase_derive.py` and applied by `firmware/tools/rebase_apply.py`.

This is an OTA file. It is not a full flash backup, a bootloader backup or an unbricking tool. Do not flash it as a TMG package or a rollback package; the phone's flash gate will not accept it either. **Non-developers must not flash it. A power loss, an interruption or a mistake can all damage the device.**
